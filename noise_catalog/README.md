# Licensed noise catalog

Only normalized 16 kHz, mono, 16-bit PCM WAV files may be ingested. Every file must have a verified source URL, attribution, SHA-256 checksum, and one of these commercial-safe licenses: CC0-1.0, CC-BY-3.0, CC-BY-4.0, or Apache-2.0.

Replays read only mirrored private GCS objects registered in `noise_assets`; runtime downloads from Hugging Face or any other public source are intentionally prohibited.

# Human-grounded voice evaluation

Lightcurve does not place telephone calls and does not use SIP, PSTN, phone
numbers, or hosted voice rooms.

## Capture

1. A Pipecat application imports `lightcurve.auto`.
2. The SDK registers the running pipeline using an outbound API connection.
3. Playground establishes direct browser-to-SDK WebRTC audio.
4. Pipecat's public observer and frame queue capture the full application path:
   VAD, STT, LLM, tools, TTS, timing, and interruptions.
5. Lightcurve stores synchronized events and derives a behavior graph.
6. The developer approves the graph as a Case in a Dataset.

## Replay

Dataset Cases preserve the real human goal, facts, decision path, timing, and
expected outcome. The replay compiler may vary phrasing, voice, pace, silence,
noise, values, and interruption timing, but it cannot leave the captured graph.
This is a constrained human-derived executor, not an unconstrained synthetic
caller agent.

Voice cloning is consent-gated. When a Playground capture is approved with voice
clone consent, Lightcurve stores the caller reference audio as a private object
URI and the replay compiler marks the temporal scenario as using the private
Chatterbox Turbo voice-clone service. If consent or reference audio is missing,
caller audio is generated by the standard private speech service instead.

## Privacy

Datasets are private to the owning customer account. Recordings, transcripts,
behavior graphs, replay policies, and derived evaluation records are not exposed
as public benchmark material through the product.

The Evaluate page is transcript-plus-audio grounded. Transcript evidence explains
what was said and how the conversation moved through the temporal graph. Audio
evidence adds delivery signals such as pauses, voiced ratio, pitch movement, and
energy movement, then those signals are merged into the observable human nuance
profile instead of relying on LLM judgment alone.
